Relatar problema viário

Informe um problema observado em uma via de Goiânia. A equipe responsável analisará o relato e definirá o encaminhamento adequado.

Exemplos para demonstração

Os exemplos abaixo são fictícios e não estão na fila oficial. Selecione um para preencher o formulário e demonstrar o fluxo.

A imagem será reduzida e armazenada no computador que executa o sistema.

Use o GPS no local do problema ou informe as coordenadas manualmente. O sistema só registra pontos dentro de Goiânia.

A localização é usada para confirmar o município. A cobertura de câmeras e o órgão responsável são verificados pela equipe durante a triagem. O registro fica no banco de dados local deste computador.
